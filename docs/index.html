Ready in a minute

Don’t install WorldEditCUI separately. It’s already included.

  1. Get Fabric.
    Fabric Loader 0.20.1 or newer for Minecraft 26.2, on Java 25.
  2. Drop it in.
    Put the mod and Fabric API in your mods folder. Mod Menu is optional.
  3. Join the server.
    MineBerry or MinePeak.
  4. Press Right Control.
    Switch on the modules you want.
