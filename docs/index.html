What it does

Every module is optional and has its own switch.

Safe LogoutSafety

Follows the server’s own PvP messages, so you can’t quit in the middle of a fight by accident. It either asks for a second click or blocks quitting until the server says you’re out. If that message never arrives, it lets go after 180 seconds.

IN PVP MODE - click again to quit

PvP Command LockSafety

While you’re in PvP mode only /r, /msg, /m, /w, /tell and your clan chat command work. Everything else is blocked, so a stray /spawn or /tpa can’t pull you out of a fight.

Tournament ModeSafety

One switch and no command can be sent at all, including ones from clickable chat and from other modules. Normal chat still works.

Tournament HUDTools

Add your friends by username and a box shows whether each is alive, dead or has left, with their last few chat messages underneath. Deaths come from the server’s own lines and spectator mode, never from player chat.

Evidence RecorderSafety

When the server announces PvP mode after you accept a /tpahere, an alert asks you to confirm. Confirming saves screenshots and a timestamped log with your coordinates and dimension, copies the player’s name, and bundles a report zip you can attach to a staff ticket.

ChatChat

Clan, Admin and Party chat on one key each, with a badge showing which is active. Mentions are highlighted with a sound, timestamps are optional, R opens a reply, and F8 searches the last 3000 lines you’ve received. Search lives in memory only.

Radial MenuTools

Hold V, move towards a slice, let go. Slices are /spawn, /tpa and /tpaccept, and they obey Tournament Mode and PvP Command Lock.

Spawn Escape and TP Danger EscapeSafety

Right Alt sends /spawn. The automatic parts catch pit drops and /tpahere traps.

They can’t tell a friend’s teleport from an enemy’s, so switch them off when you’re teleporting with friends.

Waypoints and CompassTools

Save waypoints and see them as markers on the HUD compass, with the name and distance when you look at one.

HUDMineBerry Client

FPS, Ping, Coordinates, Sprint, Clock, Keystrokes and CPS, Armor, Potion Effects, Compass, Biome and Time. Drag any box anywhere with snapping guides, keep several profiles, and overlapping boxes get a red outline. Press Right Shift for the menu.

UpdatesTools

Checks GitHub releases when the game starts and links you to the download. Nothing installs automatically. A What’s New popup shows once after each update.

Gradient generator

Colored chat text without hand-writing codes. This is the same logic as in the mod, running here.

Install

  1. Install Fabric Loader 0.20.1 or newer for Minecraft 26.2, on Java 25.
  2. Put the mod and Fabric API in your mods folder. Mod Menu is optional.
  3. Join MineBerry or MinePeak.
  4. Press Right Ctrl and switch on what you want.

Some features rely on messages and commands from the MineBerry and MinePeak servers and may not work the same elsewhere.
